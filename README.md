# Template Studio

Каталог готовых дизайнов мини-сайтов с живой настройкой стиля. Клиент выбирает
шаблон, подбирает под свой бренд цвета, шрифт, форму кнопок и скругления,
смотрит результат на компьютере / планшете / телефоне, скачивает превью в PNG
или JPG и пишет вам, чтобы заказать разработку.

Это **не конструктор сайтов**: структура и блоки шаблона неизменны — меняется
только оформление.

## Стек

React 19 · TypeScript · Tailwind CSS 4 · Vite · react-router · lucide-react ·
html-to-image

## Запуск

## Как это устроено

```
src/
  types.ts              StyleConfig, TemplateDefinition, Device
  lib/
    color.ts            парсинг hex, смешивание, контраст
    styleVars.ts        StyleConfig → полный набор CSS-переменных --tp-*
    fonts.ts            пары шрифтов (все с кириллицей)
    fontEmbed.ts        инлайн шрифтов для экспорта картинки
    exportImage.ts      растеризация превью в PNG / JPG
    presets.ts          готовые цветовые схемы
    devices.ts          ширины устройств
  hooks/
    useStyleConfig.ts   состояние настроек + сохранение в localStorage
    useFitScale.ts      масштаб «вписать в контейнер»
    useElementSize.ts   натуральный размер превью
    useInView.ts        ленивый рендер миниатюр
  templates/
    ui.tsx              общие примитивы шаблонов (кнопки, карточки, медиа)
    registry.ts         список шаблонов
    <id>.tsx            15 шаблонов, по файлу на каждый
  components/           панель настроек, превью, экспорт, диалог заказа
  pages/                GalleryPage, EditorPage
  data/studio.ts        ваши контакты, цены и сроки
```

### Ключевая идея

`styleVars(config)` превращает пять выбранных клиентом цветов в полный набор
токенов (`--tp-primary`, `--tp-surface`, `--tp-border`, `--tp-muted`,
`--tp-on-button`, радиусы, шрифты, тени). Шаблоны читают **только** эти токены —
через утилиты `t-*` из `src/index.css`. Поэтому любая палитра, которую придумает
клиент, остаётся читаемой: контрастный цвет текста на кнопках, поверхности и
границы считаются от фона и цвета текста.

### Адаптивность

Шаблоны рендерятся в настоящей ширине устройства (1440 / 834 / 390 px) и потом
масштабируются CSS-трансформом, чтобы поместиться в область просмотра.
Поэтому внутри шаблонов используются **контейнерные** запросы Tailwind
(`@2xl:`, `@4xl:`), а не оконные (`md:`, `lg:`) — иначе телефонный кадр на
широком мониторе показывал бы десктопную вёрстку.

### Экспорт

`captureNode()` растеризует немасштабированный узел через `html-to-image` с
`pixelRatio: 2` (с ограничением по площади, чтобы очень длинные страницы не
уронили canvas). Шрифты инлайнятся вручную (`fontEmbed.ts`): запрашиваются
только семейства активной пары и только латиница + кириллица — встроенный
хелпер html-to-image тянет все ~90 начертаний и работает почти минуту.

## Добавить новый шаблон

1. Создайте `src/templates/mytemplate.tsx`:

```tsx
import type { TemplateDefinition } from '../types';
import { Btn, Section } from './ui';

function MyTemplateSite() {
  return (
    <div className="tpl">
      <Section>
        <h1 className="text-[2.5rem] @2xl:text-[3.4rem]">Заголовок</h1>
        <Btn size="lg">Кнопка</Btn>
      </Section>
    </div>
  );
}

export const mytemplate: TemplateDefinition = {
  id: 'mytemplate',
  name: 'Название',
  category: 'Категория',
  description: 'Одно-два предложения для карточки в каталоге.',
  tags: ['ключевые', 'слова', 'для', 'поиска'],
  defaults: {
    primary: '#4f46e5',
    secondary: '#06b6d4',
    button: '#4f46e5',
    background: '#ffffff',
    text: '#111827',
    buttonShape: 'soft',
    font: 'inter',
    cardRadius: 16,
  },
  Component: MyTemplateSite,
};
```

2. Добавьте его в массив `TEMPLATES` в `src/templates/registry.ts`.

Всё: карточка в каталоге, миниатюра, редактор, три устройства и экспорт
заработают сами.

Правила, которых стоит держаться в шаблонах:

- корневой элемент — `<div className="tpl">`;
- никаких захардкоженных цветов, радиусов и шрифтов — только `t-*` классы и
  `var(--tp-*)`;
- только контейнерные брейкпоинты (`@md:`, `@2xl:`, `@4xl:`), не оконные;
- в кастомных сетках используйте `minmax(0,1fr)` вместо `1fr`, иначе длинное
  слово растянет колонку на телефоне.

## Настройка под себя

Ваши контакты, цена и срок — в одном файле: `src/data/studio.ts`. Больше нигде
они не захардкожены.
