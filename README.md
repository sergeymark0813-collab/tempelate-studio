# Template Studio

Генеративная дизайн-студия. Пользователь отвечает на вопросы — приложение
собирает уникальный дизайн с нуля: палитру, шрифтовую шкалу, сетку, композицию
и все блоки. **Готовые шаблоны при генерации не используются**: два одинаковых
брифа дают два разных результата.

Результат остаётся структурой данных, а не картинкой, поэтому его можно
редактировать, смотреть на трёх устройствах, публиковать в общей галерее и
экспортировать в PNG.

```
Вопросы → Генерация → Редактор → Превью → Публикация → Экспорт
```

## Что умеет

**Динамическая анкета.** Четыре независимых трека — сайт, логотип, интерфейс,
графика — со своими наборами вопросов. Для сайта вопросы дополнительно
подстраиваются под сферу: ресторан спрашивают про кухню и бронирование,
IT-компанию — про стек и кейсы. 19 сфер плюс произвольная, вписанная словами.

**Ответы влияют на результат.** Вариант ответа может нести `adds` — блоки,
которые попадут в композицию. «Нужна онлайн-бронь» действительно добавляет блок
брони; «без шестерёнок» исключает соответствующие мотивы из подбора знака.

**Генератор логотипа** — отдельный конвейер: 33 мотива по семантическим полям и
шесть принципов построения знака. Подход «первая буква + круг» исключён; буквы
используются только в монограмме и текстовом логотипе, и там они строятся как
геометрия.

**Редактор.** Цвета с палитрой из 139 образцов, гармониями по цветовому кругу и
вводом в HEX / RGB / HSL. Шрифты, скругления, отступы, базовый кегль. Тексты,
кнопки, ссылки, изображения и видимость каждой секции.

**Responsive-превью.** Desktop / Tablet / Mobile — артборд рендерится в реальной
ширине устройства и по-настоящему перестраивается, а не масштабируется.

**Сообщество.** Публикация с обязательным описанием, галерея чужих работ, оценки
звёздами: одна на человека, повторная заменяет прежнюю.

**Три языка** — English (по умолчанию), Русский, Հայերեն.

## Как устроена генерация

```
Ответы
  ↓  analyze / flow.ts        разбор брифа, выбор трека и сферы
  ↓  palette.ts               гармония по цветовому кругу + контроль контраста
  ↓  typography.ts            пара гарнитур + вычисленная модульная шкала
  ↓  tokens.ts                отступы, скругления, тени, сетка, движение
  ↓  compose.ts               архетип раскладки → блоки с вариантами и спанами
  ↓  content.ts               тексты под сферу, а не lorem ipsum
Project { ds, frames[], analysis }
```

Ничего не выбирается из готового. Палитра строится в HSL от одного тона по
правилу гармонии и проверяется по WCAG; шрифтовая шкала вычисляется из
модульного отношения и базового кегля; композиция получает архетип, а каждый
блок — вариант, число колонок, выравнивание и плотность.

Зерно случайности берётся заново на каждый запуск и записывается в проект,
поэтому результат можно воспроизвести, но нельзя предсказать.

## Структура

```
src/
  lib/
    studio/           движок генерации
      flow.ts         динамическая анкета, четыре трека
      niches.ts       19 сфер со своими вопросами
      products.ts     18 типов продуктов и их артборды
      palette.ts      цветовые гармонии
      typography.ts   пары гарнитур и модульная шкала
      tokens.ts       дизайн-система целиком
      compose.ts      архетипы раскладки и сборка блоков
      content.ts      генерация текстов по сферам
      generate.ts     оркестрация
      logo/           отдельный конвейер логотипа
    community/        публикация, рейтинг, пользователи
    i18n/             словари интерфейса и корпуса генератора
    color.ts          HSL ↔ HEX, контраст, гармонии
    exportImage.ts    растеризация превью в PNG / JPG
  components/
    studio/           рендерер артбордов, редактор, мастер
    community/        публикация и звёзды
  pages/              StudioPage, CommunityPage, GalleryPage, EditorPage
  templates/          45 готовых шаблонов — отдельный каталог на /templates
```

## Готовность к бэкенду

Аккаунтов и сервера нет. Чтобы это не мешало подключить их позже, доступ к
данным спрятан за контрактами:

| Что | Контракт | Реализация сейчас |
| --- | --- | --- |
| Пользователи, публикации, оценки | `lib/community/types.ts` | `lib/community/store.ts` (localStorage) |
| Реклама | Google AdSense | `lib/adsense.ts`, включается переменными окружения |

Подключение сервера — замена одного модуля; вызывающий код и интерфейс не
меняются.

## Реклама

Единственная рекламная система — Google AdSense. Без заданного publisher id
разметка не выводится и скрипт не грузится:

```bash
cp .env.example .env.local
```

## Переводы

Интерфейс переведён полностью. Корпус генератора (сферы, вопросы, блоки,
генерируемые тексты) переводится по ключам в `lib/i18n/engine.ts`; непереведённый
ключ показывает исходный русский текст, а не пустоту.

Переведено: типы продуктов, базовые вопросы анкеты, выбор сферы целиком.
В работе: вопросы внутри сфер, разделы, блоки, генерируемое наполнение.
